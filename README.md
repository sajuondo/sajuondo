선희, 작업 끝났어요! 1차 슬림화 + 온도살롱 커뮤니티가 들어간 새 구조입니다.

## 📁 파일 구조

```
sajuondo/
├── index.html               ← 홈 + 무료 사주 분석
├── salon.html               ← 온도살롱 커뮤니티 (신규)
├── report.html              ← 심화 리포트 (준비중 상태)
├── supabase_schema.sql      ← Supabase 테이블 생성 SQL
└── shared/
    ├── design.css           ← 공통 디자인 시스템
    ├── saju-engine.js       ← 만세력 엔진 + DB (A 파일 자산 그대로)
    └── saju-auth.js         ← Supabase 인증 + 사주 데이터 영속화
```

원본 A 파일이 한 파일 **3,390줄**이었는데, 이제 깔끔하게 분리됐어요.
shared/ 폴더가 핵심 자산이고, 페이지 3개가 이걸 공유해요.

---

## 🚀 배포 순서 (오늘 해야 할 일)

### 1. Supabase 테이블 생성 ⭐ 가장 먼저
1. Supabase 대시보드 접속 → 본인 프로젝트 선택
2. 왼쪽 사이드바 **SQL Editor** 클릭
3. `supabase_schema.sql` 파일 내용 전체 복사
4. 붙여넣고 **Run** 클릭
5. "Success" 뜨면 완료

테이블 5개가 만들어져요:
- `user_saju` — 분석 결과 영속화
- `user_profile` — 닉네임
- `posts` — 게시글
- `comments` — 댓글
- `likes` — 좋아요

RLS(Row Level Security) 정책도 자동 적용돼요. **글쓰기는 사주 분석 1회 필수**가 DB 수준에서 강제됩니다.

### 2. Google OAuth 설정
Supabase 대시보드 → **Authentication → Providers → Google → Enable**
(이미 설정되어 있을 수도 있어요. 안 되어 있으면 [공식 가이드](https://supabase.com/docs/guides/auth/social-login/auth-google) 참고)

### 3. 파일 업로드 (Netlify)
`sajuondo/` 폴더 전체를 Netlify에 그대로 드래그&드롭하면 끝.
혹시 GitHub 연동 쓰고 있으면 `sajuondo/` 안의 파일들을 리포지토리 루트에 push.

## ⚠️ 알아야 할 한계점

### 1. AI 해석이 placeholder예요
현재 `index.html`의 AI 해석은 임시 텍스트입니다.
**왜냐하면**: 클라이언트(브라우저)에서 직접 Anthropic API를 호출하면 API 키가 노출돼요.
**다음 단계**: Supabase Edge Function으로 옮겨야 합니다.

```
브라우저 → Supabase Edge Function → Anthropic API → 응답
```

이거 다음에 같이 할 수 있어요. 그 전까지는 "내 사주의 4기둥/오행/온도"는 정확히 나오니까, 사용자가 가치를 느끼는 데는 문제 없어요.

### 2. 결제 미연동
`report.html`에 "준비중" 버튼만 있어요.
**다음 단계 (STEP 2)**: 토스페이먼츠 연동 + 구독 관리 로직.

## 🌡️ 온도살롱 운영 팁

선희가 직접 챙기면 좋은 부분:

### 초반 1~2주
1. **씨앗 글 본인이 직접 작성** — 각 방마다 2~3개씩
   - 차가운 방: "겨울 사주로 살아가는 건 어떤 느낌인가요"
   - 연애방: "을목 일주는 진짜 다 비슷한가요?"
   - 자유방: "사주 보고 직업 바꾼 사람 있나요"
2. **댓글 빨리 답하기** — 초반엔 본인 댓글 = 분위기 메이커
3. **유튜브 영상 끝에 "온도살롱에서 같이 얘기해요" 코멘트** — 유입 연결

### 자연스러운 성장 흐름
사주 분석 → 결과 페이지 CTA 카드 → 살롱 입장 → 글 읽기 → 가입 → 글쓰기
이 흐름이 자연스럽게 만들어져 있어요.
